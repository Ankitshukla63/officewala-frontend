# Office Wala Frontend

React + Vite SPA frontend for the "Office Wala" platform, with the authentic Indian truck-art theme, talking to Spring Boot on `http://localhost:8080`.

## Quick Start

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run in Development**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173`.

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Requirements
- Node.js 18+
- Office Wala Spring Boot backend running on `http://localhost:8080`
